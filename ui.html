在既有畫面上補上流程

  1. 按「開始連線」，選取 frame 或 component。
  2. 點物件四邊的起點，再選另一個物件並點終點。
  3. 選取已建立的箭頭，即可修改文字與樣式。

範圍註記：框選物件，或按 R 畫矩形，再建立編號外框與旁側備註。

切換選取時，未儲存草稿會保留到本次 plugin 關閉。按 ⌘ / Ctrl + Enter 儲存；面板內按 Esc 取消起點。

連線只在 plugin 開啟時跟隨物件。註記範圍固定，可調整外框後儲存。節點目前在選取後顯示，尚不支援 hover。
